# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository. It is not part of the website: `docusaurus.config.ts` excludes it through `docs.exclude`.

## Build commands

```
npm run start      # Dev server
npm run build      # Production build into build/
npm run serve      # Preview the production build
npm run typecheck  # tsc
npm run clear      # Clear .docusaurus cache
```

## Architecture

This is a [Docusaurus](https://docusaurus.io) 3 site (classic preset, TypeScript) in docs-only mode: the docs plugin uses `path: '.'` and `routeBasePath: '/'`, so every `.md` file at the repo root is site content and keeps a root-relative URL (`gopl/1.md` → `/gopl/1`). Nothing needs to be generated before building.

Content lives in project directories at the repo root: `agent_diary/`, `ai_readings/`, `cmd/`, `frontend/`, `gopl/`, `how_to/`, `missing_2020/`, `modern_js/`, `rust_book/`. Images sit next to the notes that reference them.

**Sidebar**: `sidebars.ts` uses an autogenerated sidebar plus a custom `sidebarItemsGenerator` that reproduces the ordering of the old site — frontmatter `order` first, then `date`, then a numeric-aware, Chinese-aware natural sort on the doc title. `numberPrefixParser` is disabled so file names (and thus labels and URLs) are never rewritten. Category labels come from directory names, doc labels from the first heading.

**Frontmatter**: `unlisted: true` keeps a page out of the sidebar (`index.md`, `TOREAD.md`); `slug: /` marks the home page. The `date` and `origin.*` fields are kept in the notes as data but are not rendered anywhere.

**Markdown pipeline** (`docusaurus.config.ts`): `remark-math` + `rehype-katex` with the macros `\set`, `\Z`, `\R`, `\Q`, `\C`; `remark-cjk-friendly`; Mermaid diagrams; admonitions plus the custom `details` keyword, written as `:::details[标题]`.

**Theme overrides** in `src/theme`: `DocItem/Content` (medium-zoom on images) and `Admonition/Types` (the `details` container). `src/css/custom.css` holds brand colors and shared reading styles. Static files (favicon, `robots.txt`) go in `static/`.
